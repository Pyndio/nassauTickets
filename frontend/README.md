# Nassau Tickets — Frontend

Frontend do sistema Nassau Tickets, desenvolvido em React com Vite.

## Sobre

Esta parte do projeto é responsável pela interface utilizada para:

- Emissão de senhas;
- Visualização da fila de atendimento;
- Chamada de senhas pelo guichê;
- Rechamada de senhas;
- Início e finalização do atendimento;
- Exibição do painel público.

## Tecnologias

- React
- JavaScript
- JSX
- Vite
- CSS
