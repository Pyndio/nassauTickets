# Identidade Visual (Branding) — Nassau Tickets

## 1. Sobre o projeto

O **Nassau Tickets** é o sistema de controle de atendimento desenvolvido para a disciplina de Coding, em parceria visual com a identidade da UNINASSAU, instituição de origem do projeto acadêmico.

> Este documento registra as decisões visuais já adotadas no sistema. Arquivos de logo em alta resolução, variações de marca e guia de estilo completo podem ser adicionados nesta pasta conforme forem produzidos.

## 2. Nome e propósito da marca

- **Nome do sistema:** Nassau Tickets
- **Proposta:** transmitir organização e agilidade no atendimento, remetendo a sistemas de senha de laboratórios e serviços de atendimento ao público.

## 3. Paleta de cores — Identificação por tipo de senha

O Painel Público usa cores para diferenciar rapidamente o tipo de cada senha chamada, facilitando a leitura à distância:

| Tipo | Cor | Código sugerido | Significado |
|---|---|---|---|
| **SP** — Prioritária | 🟡 Amarelo | `#F4C430` | Atenção — atendimento prioritário |
| **SE** — Retirada de Exames | 🔴 Vermelho | `#D6362A` | Atendimento rápido e operacional |
| **SG** — Geral | 🔵 Azul | `#2F6690` | Atendimento padrão |

## 4. Cores institucionais (referência UNINASSAU)

| Uso | Cor | Código sugerido |
|---|---|---|
| Cor primária | Azul institucional | `#1C3D5A` |
| Cor de destaque / ação | Verde | `#2F9E58` |
| Fundo neutro | Cinza claro | `#F5F8FA` |
| Texto principal | Cinza escuro | `#2B2F38` |

## 5. Tipografia

- **Recomendação:** fonte sem serifa (sans-serif), priorizando legibilidade em telas de painel visualizadas à distância — ex: `Helvetica`, `Arial` ou `Inter`.
- Títulos em peso **bold**, textos de apoio em peso regular.

## 6. Logotipo

- O logotipo da UNINASSAU está presente na interface do sistema (tela inicial), conforme identidade institucional do projeto.
